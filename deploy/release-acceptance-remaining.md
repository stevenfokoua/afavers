# Remaining release acceptance — 31 October 2026

This is a verification plan against `openspec/changes/production-ready-job-workflows/tasks.md` and the implemented code, not a receipt that these checks passed. Leave checklist items unchecked until the release coordinator links evidence for the exact final source commit. Goal 4 remains excluded.

## Automated browser coverage

The real isolated backend suite covers search, manual applications, notes/checklists/stages/settings, agenda navigation, Hot Picks, phone return focus/filters, captured signup/recovery mail, cross-context collections and concurrent saved-search quotas. It uses real Postgres/Auth/REST; worker endpoints deliberately do not return fake success.

The new `client/e2e/accessibility.spec.ts` adds:

- Native filter-dialog Tab/Shift+Tab containment, Escape dismissal, trigger focus return, a computed keyboard outline and detail-tab arrow/Home keys.
- A real private long-content record at **320 CSS pixels**, in EN/DE and both themes, list/detail overflow checks and an actual empty search result.
- Real reduced-motion media emulation: instrument authored detail/save Web Animations calls, require zero calls, and verify a note still reaches the backend.

These tests type-check locally. Browser execution is pending on the final candidate. Chromium desktop and WebKit phone are browser-engine projects, not installed Edge/Firefox, physical phones, iOS Safari, VoiceOver or native Capacitor acceptance. A computed outline check establishes neither sufficient contrast nor an unobscured focus indicator across every surface.

For every manual result, record commit/release, environment/version, scenario, observed result, evidence path and unresolved limit. A blocker or unavailable device remains an explicit outstanding gate; do not silently check the whole goal because the deploy or CI succeeded.
